01 / The ideaLess gear. More understanding.

A simple rig.
A considered design.

Plug in a guitar. Shape its character. Hear it through a speaker. MultiFX brings that familiar experience into one compact engineering project.

The goal is a standalone practice amplifier with clean and driven sounds, equalization, and controls you can reach for. Every interface is part of the work, from the pickups to the power stage.

01 / Input conditioner

Respect the guitar.

An MCP6002 stage on the main PCB buffers the guitar signal and adapts its level for the DSP. The input uses an approximately 1 MΩ bias path and a jumper to select unity or ×2 gain.

Main-PCB conditioner · MCP6002 · gain ×1 / ×2

02 / Analog-to-digital conversion

A signal becomes samples.

The conditioned guitar signal enters an ADC on the ADAU1701. This is where the analog path becomes digital; its usable range must be checked against the actual input circuit.

Inside the TSA1701 module · input levels to verify

03 / ADAU1701 processing

Give the sound a direction.

The TSA1701 provides the dedicated audio DSP. Clean routing, drive, equalization, and level management remain the processing target; their behavior must be established with the deployed SigmaStudio program.

ADAU1701 · SigmaStudio project not yet included in the repository

04 / Digital-to-analog conversion

Back into the physical world.

The DAC reconstructs an analog output from the processed samples. This signal feeds the power amplifier, with gain staging chosen to avoid accidental clipping.

Inside the TSA1701 module · output compatibility to verify

05 / Power amplifier and speaker

Make the signal heard.

The interface sheet specifies an external PAM8302 amplifier module and a 4 Ω / 5 W speaker. Usable output, supply demand, and thermal behavior still require measurement after assembly.

5 V system · external PAM8302 module · acoustic performance pending
↳

Control takes its own path.

The PCB includes an STM32F030 for buttons, LEDs, and DSP parameter control over I²C, plus a CP2102N USB-to-UART interface. Audio stays in the TSA1701. Control firmware, startup coordination, and module interaction remain to be demonstrated on hardware.

MCU → I²C → DSP

01

Architecture

Documented

A five-sheet schematic documents power, guitar conditioning, control, and audio-module interfaces. The design uses a 5 V system, an MCP6002 input stage, an STM32 controller, and external TSA1701 and PAM8302 modules.

02

PCB & exports

Available

The repository contains the two-layer PCB design, native Altium project, schematic PDF, Gerber and drill outputs, BOM, Draftsman document, and STEP model. These files document the supplied design; they do not establish fabrication or measured performance.

03

Fabrication & assembly

Pending

Reconcile the manufacturing outputs with the selected PCB revision, fabricate the board, assemble components, and connect the external modules. The component boundary permits supplied library parts and confirmed local purchases mounted directly on the PCB.

04

Bench validation

Pending

Check power rails, demonstrate clean audio, verify autonomous DSP startup, and command a parameter change from the controller. Record audio, current, and thermal measurements with their test conditions before presenting complete-system results.

Current evidence: Altium source, schematic PDF, PCB manufacturing outputs, BOM, and STEP model. Fabrication, assembly, and bench validation are pending.
